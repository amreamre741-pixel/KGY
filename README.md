# KGY — نظام تسيير محلات قطع غيار السيارات والشاحنات

تطبيق ويب (ويخدم كتطبيق هاتف PWA) لتسيير المخزون متعدد المحلات، الباركود، تصوير القطع والبحث بالصورة، استيراد Excel / Zinostoke، شاشة البيع والفواتير (A4 و80mm)، دفتر الكريدي، حساب الزكاة السنوية لكل محل، الموردين وفواتير الشراء، التحويل بين المحلات، ولوحة التقارير والفايدة الصافية.

## الدخول لأول مرة بعد التنصيب
- **اسم المستخدم:** `admin`
- **كلمة السر الافتراضية:** `kgy12345` *(بدّلها من صفحة **العمال** غير تدخل لأول مرة)*

## التشغيل المجاني على Vercel + Neon
1. افتح [vercel.com/new](https://vercel.com/new) وسجّل الدخول بحساب **GitHub**.
2. اختار المستودع **kgy** واضغط **Import** ثم **Deploy**.
3. من لوحة المشروع في Vercel، ادخل لتبويب **Storage** -> **Create Database** -> **Neon (Serverless Postgres)** -> اختر الخطة المجانية (**Free**) واربطها بالمشروع، ثم اضغط **Redeploy**.
